# Credits and provenance

## Vehicle and textures
Suzuki Ciaz 2017 visual model and texture ZIP supplied by the project owner. Converted geometry retains source UVs and normals, changes coordinate axes, sets length to 449 cm, separates rotating assemblies and batches static material sections. Textures are resized to a maximum of 1024 pixels.

The supplied files contain Sketchfab-origin naming. No ownership or redistribution license for the car is inferred. Keep the original creator's license with the project before a public release. The model is not presented as newly authored artwork.

Reference dimension: https://www.suzuki.com.np/ciaz
4490 mm length and 2650 mm wheelbase. Exact 2017 regional engine/trim remains unspecified; physics values are prototype tuning defaults, not claimed factory specifications.
